# 物派 V1.2.2

改进上手体验，保留悬停菜单，并修复浮层切换、撤销范围与小屏幕操作问题。

- 顶栏、保存和更多纹样支持悬停预览；短暂停留展开、移开缓冲收起，单击固定，再点关闭。触屏继续点击操作。
- “保存与作品”按图片、可继续编辑的作品、模型分组；作品支持保存、打开与从最近作品恢复。
- 主浮层互斥；派库栏目齿轮保留父面板，Esc优先关闭子菜单并返回焦点，命名和确认操作不误关父菜单。
- 底栏明确显示“转速”和“疏密与配色”；首选项明确表面与派库撤销范围，鼠标经过不会切换快捷键目标。
- 修复小窗口浮层遮挡底栏、栏目管理焦点和色球删除角标命中不稳定；更新中英文界面、使用说明、隐私说明与简明PDF。

## 下载

按平台选择一个ZIP；另有独立安装APK与SHA256校验表：

- **Desktop.zip**：Windows便携应用及备用HTML。
- **Android.zip**：签名APK、备用HTML及说明；也可直接下载 **Android.apk**。
- **iPhone.zip**：备用HTML和原生USDZ模型；不包含IPA。
- **Linux.zip**：x86_64 AppImage、启动脚本与备用HTML。
- **SHA256SUMS.txt**：校验各下载文件。
